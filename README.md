# mytoolbox

AI-powered lesson planning for Zambian teachers

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- npm or yarn

### Frontend Setup
```bash
cd mytoolbox
npm install
npm run dev
```

### Backend Setup
```bash
cd mytoolbox/backend
npm install
npm run dev
```

### Environment Variables
Create a `.env` file in the backend directory:
```
PORT=5000
JWT_SECRET=your-secret-key
OPENAI_API_KEY=your-api-key
```
